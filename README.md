> The official browser extension workspace for the **Tiffy** productivity suite.  
> Built with modern **Manifest V3** standards, compatible across **Google Chrome**, **Brave Browser**, and **Microsoft Edge**.

## 🚀 Quick Start (Development / Load Unpacked)

All extensions in this repository are written in pure modern JavaScript, HTML5, and CSS3 without mandatory build or bundling steps.

1. Open your Chromium browser extension manager:
   - **Chrome**: `chrome://extensions/`
   - **Brave**: `brave://extensions/`
   - **Edge**: `edge://extensions/`
2. Toggle on **Developer mode** in the top-right corner.
3. Click **Load unpacked** (โหลดส่วนขยายที่คลายการบีบอัดแล้ว).
4. Select the specific extension folder (e.g., `tiffy-extension/tiffy-scroll`).
