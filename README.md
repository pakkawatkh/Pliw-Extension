## ✨ Usage Examples

### 📸 Pliw Scroll
1. Open any long webpage and click the **Pliw Scroll** icon in your browser toolbar.
2. Click **Capture Full Page** — it scrolls automatically, hides sticky headers, and stitches a Retina 2x PNG canvas.
3. Use the **8-handle Crop Studio** to crop any region and press **Copy (`⌘V`)** or **Download PNG**.

### 📍 Pliw Geo
1. Click the **Pliw Geo** icon and pick any location on the interactive map (or search by place name / lat-lng).
2. Enable spoofing and optionally turn on **GPS Jitter** or use **N/S/E/W Nudge** to simulate live movement on Google Maps or web check-in apps.

## 🚀 Installation Guide (วิธีติดตั้งบน Chrome / Brave / Edge)

1. Download the `.zip` file for the extension you want from the table above (or clone this repo).
2. Unzip the downloaded file into a permanent folder.
3. Open your browser's Extensions page:
   - **Chrome:** `chrome://extensions/`
   - **Brave:** `brave://extensions/`
   - **Edge:** `edge://extensions/`
4. Enable **Developer mode** (top-right corner).
5. Click **Load unpacked** (โหลดส่วนขยายที่คลายการบีบอัดแล้ว) and select the extension folder (`pliw-scroll` or `pliw-geo`).
